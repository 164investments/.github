# Security policy

## Report a vulnerability

Please don't report security problems in a public issue, discussion or pull request.

- **Public repositories:** use **Report a vulnerability** on the repository's **Security** tab. Only the maintainers see the report.
- **If that button isn't there:** message an owner of this GitHub organization privately and say you have a security report. Don't include the details until they reply.

Please include what is affected, how to reproduce it, and what someone could do with it. We aim to reply within 3 business days.

## Secrets

If you find a key, token or password in any of our repositories, report it the same way. Don't use it, even to test whether it works.
